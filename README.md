# Linh Anh · Trải nghiệm số sau 12 tháng

Bộ màn hình minh họa (mockup tương tác) cho chiến lược chuyển đổi số Linh Anh 2027–2029.
Số liệu trong các màn hình là minh họa, không phải dữ liệu thật.

## Xem trên máy
Mở `index.html` (cổng ứng dụng nội bộ) bằng trình duyệt, chọn từng chức năng.

## Đưa lên GitHub Pages
1. Tạo repository mới, tải toàn bộ các file trong thư mục này lên nhánh `main` (để `index.html` nằm ở thư mục gốc).
2. Vào Settings → Pages, chọn Source là `Deploy from a branch`, nhánh `main`, thư mục `/ (root)`.
3. Sau khoảng một phút, trang chạy tại `https://<tên-tài-khoản>.github.io/<tên-repository>/`.
